# 真机手动验收清单

> 单元测试覆盖的是纯逻辑，**设备连接、真实录制、截图识别**只能在装有桌面的真实环境里验证。
> 本文档给出可执行程序的位置与逐项验收步骤，按 1→8 顺序走完即可覆盖全部核心链路。

## 0. 准备

构建产物（任选其一）：

| 类型 | 路径 |
| --- | --- |
| 免安装 exe | `src-tauri\target\release\maa-wizard.exe` |
| NSIS 安装包 | `src-tauri\target\release\bundle\nsis\MaaWizard_0.1.0_x64-setup.exe` |

前置条件：

- `maa-sdk/` 已下载（`make fetch-sdk`），否则「加载动态库」会失败
- 直接双击 exe 即可：**不需要**先把工作目录切到仓库根，程序会自动逐级向上定位 `maa-sdk` 与 `resource`
- 录制会捕获**全局**鼠标与键盘，验收时建议先打开一个记事本作为操作对象
- 重新构建前请先**关闭正在运行的 MaaWizard**，否则 exe 被占用会导致覆盖失败

## 1. 库与资源加载

1. 打开「运行」页，动态库路径填 `maa-sdk/bin/MaaFramework.dll`，点「加载动态库」
   - 预期：日志出现 `MaaFramework v5.x 已加载：<绝对路径>`
2. 资源目录填 `resource`，点「加载资源」
   - 预期：日志出现资源加载成功；若 10 秒未完成会超时报错

## 2. 设备连接（Win32）

1. 在「运行」页，点「列举窗口」
   - 预期：列出当前所有可见窗口的 `hwnd / 类名 / 标题`
2. 选中「记事本」或任一窗口并连接
   - 预期：右下或日志显示当前控制器变为 `Win32 hwnd=...`
3. 回到「运行」页确认「当前控制器」不是 `none`

## 3. 跑通示例 pipeline

1. 入口节点填 `Demo`，点「运行」
2. 观察日志区是否持续出现 `事件 Task ...` 之类的节点执行回显
3. 点「停止」，再点「查看状态」
   - 预期：状态返回正常，无崩溃

## 4. 图编辑器

1. 「图编辑器」页点「打开」，加载 `resource`
2. 画布应渲染出节点，`next` 为蓝色实线、`on_error` 为红色虚线
3. 点「新建节点」→ 画布出现新节点且自动选中
4. 在下方属性面板把识别类型改成 `TemplateMatch`
   - 预期：出现「请先通过框选截图生成模板图」提示
5. 点「校验」
   - 预期：TemplateMatch 缺 `template` 时报出错误，字段定位到 `recognition.template`，点击该条可跳转到节点
6. 补上参数后再次「校验」，应显示「校验通过」
7. 切换导出版本为 V1 / V2 各保存一次，用文本编辑器打开
   `resource/pipeline/maawizard.json` 确认格式正确（V1 参数平铺、V2 收进 `param`）

## 5. 录制（会捕获真实输入，注意别误触）

1. 切到「录制」页，选择智能模式，点「开始录制」
2. 在记事本里点一下、输入 `hello`、按一次回车
3. 回到应用点「停止录制」，再点「提交」
   - 预期：生成若干节点并按录制顺序用 `next` 串联
4. 切回「图编辑器」确认新节点已出现
   - 预期：点击类节点是 `TemplateMatch + Click`（**不是裸坐标 DirectHit**），
     连续输入合并为单个 `InputText`，回车生成 `ClickKey`

## 6. ROI 框选与模板抓取

1. 「图编辑器」页点「截取屏幕」
   - 预期：显示当前桌面截图
2. 在截图上拖拽出一个矩形
   - 预期：蓝色选区跟随，右上角显示选区尺寸
3. 先在画布选中一个节点，再点「抓取选中区域为模板」
   - 预期：日志出现 `已抓取模板 roi_xxx.png，roi=[x, y, w, h]`，
     该节点自动切换为 `TemplateMatch` 并填好 `template`
4. 确认文件确实落在 `resource/image/` 下（**不是** `src-tauri/target/release/` 里）

## 7. AI 面板（可选，开发者调试台）

> 注意：AI 面板已从主界面导航移除（属开发者调试台，非终端用户功能，代码保留可恢复）。
> 如需验证，请在 dev 模式下手动进入；普通验收可跳过本步。

1. 点「探测环境」
   - 预期：显示 python / uv / uvx 的探测结果
2. 若未安装 Python：应给出安装建议且**不崩溃**（ADR 0004 的优雅降级）

## 8. 已知限制（暂不修，验收时请忽略）

- 仅 Windows 桌面端（Win32 控制器非跨平台）
- Adb 连接需要本机有模拟器/真机，本次可不验
- OCR 需要 OCR 模型随资源包提供，示例包未带模型

## 反馈模板

出问题时请把以下信息一起给出，便于定位：

1. 操作到第几步、点了哪个按钮
2. 界面底部「日志」区的全部内容（从最近的失败点往上 10 行）
3. 是否弹出错误对话框；若有，完整的错误信息
4. 相关产物（如 `resource/pipeline/maawizard.json` 的内容）
