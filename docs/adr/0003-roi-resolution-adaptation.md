# ROI 与模板的分辨率适配策略

「抗分辨率变化」是本项目相对按键精灵的核心卖点。决定：模板匹配（TemplateMatch）天然抗平移/缩放——识别基于图像特征而非坐标，点击目标取自识别命中框（hitbox），与截图分辨率解耦；ROI 仅作为识别**搜索区域**，以「截图时分辨率 + 绝对像素」存储，运行期由 MaaFramework 在当前分辨率下重新识别。

- **关键澄清**：本项目**不依赖坐标缩放来抗变**，而是依赖「重识别」。坐标模式（M2.2）仅用于固定界面，明确标注为脆弱。
- **对 ROI 字段的影响**：`roi` 是搜索框而非点击点；编辑器导出 ROI 时无需做归一化，但应记录参考分辨率以便调试时提示。
- **状态**：accepted
