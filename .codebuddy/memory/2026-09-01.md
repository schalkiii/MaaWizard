# 2026-09-01

## 图编辑器内嵌 MaaPipelineEditor（离线内嵌）

- 用户确认把 MaaPipelineEditor (MPE, kqcoxn) 离线内嵌进 Tauri 应用，作为图编辑器。
- MPE 前端是 React+ReactFlow 纯静态网页，自带 `Iframe/` 集成模式；其 LocalBridge 协议目前**只实现文件管理**（列目录/打开/保存/创建，WebSocket `ws://localhost:9066`，消息 `{path, data}`）。截图/控制器连接官方未实现，由我们自己的运行页负责。
- 实现：`src-tauri/src/mpe_bridge.rs` —— Tauri 启动时自动拉起的 WS 文件桥，根目录 `resource/`，把 MPE 的 pipeline 读写对接到我们资源包。依赖新增 tokio(-tungstenite)/futures-util/json5。
- 前端构建：克隆 `tools/MaaPipelineEditor`，`Editor` 下 `npm install` + `npm run build -- --mode mpe`（base=/mpe/），产物复制到 `public/mpe/`（Vite dev/构建都从 /mpe/ 提供）。
- `src/App.vue` 图编辑器页默认内嵌 `<iframe src="/mpe/">`，并提供「MaaPipelineEditor / 内置编辑器」切换，自研编辑器保留为回退。
- `tauri.conf.json` 的 `security.csp` 为 null，不会拦截 MPE 的 inline script/ws/worker。
- 运行：`npm run tauri dev`（Rust 端会起 9066 文件桥，前端 iframe 连上即可离线编辑 resource/ 下 pipeline）。
- 注意：`tools/MaaPipelineEditor/Editor/node_modules` 体积大，可删除；重新构建 MPE 需重跑 install+build。
