## 修复 MPE「连不上」文件桥 + 完善验证

- 根因：MPE 默认 `wsAutoConnect=false`，启动时不会主动连桥；且 `localhost` 在我方 Rust 桥只绑 IPv4(127.0.0.1:9066) 时，浏览器解析到 IPv6(::1) 会连不上。
- 修复：
  - `tools/MaaPipelineEditor/Editor/src/services/server.ts`：WS 连接地址由 `ws://localhost` 改为 `ws://127.0.0.1`（构造器与 setPort 两处）。
  - `src/App.vue`：内嵌 iframe 的 src 加参数 `?link_lb`（注意参数名是 `link_lb` 带下划线，对应 `urlHelper.ts` 的 `LINK_LB_PARAM`；写成 `linkLb` 无效）。该参数让 MPE 启动时自动 `localServer.connect()` 到 9066。
  - MPE 端 `mpe_bridge.rs` 协议路径完全匹配（`/etl/open_file|save_file|create_file` ↔ `/lte/file_*`、`/ack/*`），握手只看 `success`，无需改。
- 重构建并覆盖：重装 node_modules → `npm run build -- --mode mpe` → 覆盖 `public/mpe`；主前端 `npm run build` 同步 `dist/mpe`。
