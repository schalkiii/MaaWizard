## 踩坑（复用价值高）

- `vi.mock` 工厂会被提升到 import 之前，其中的桩函数必须用 `vi.hoisted(() => ({ fn: vi.fn() }))` 声明，否则报「不能先于初始化访问」。
- VTU 的 `find(".stage")` 返回 `DOMWrapper<Element>`；把元素传给辅助函数时要显式标注该类型，否则 vue-tsc 认为联合类型上没有 `trigger`。
- `pipeline` 是私有模块（`mod pipeline;`），模块内的 `pub` 项若无人使用仍会被 clippy 判为 dead code —— 只再导出真正被外部使用的类型。
  解决方式：让 `save()` 复用 `has_errors` 给出校验提示，既消除警告又有产品价值。
- markdownlint MD060：表格分隔行必须写 `| --- | --- |`（两侧带空格），写成 `|---|` 会报错。
- `git push` 偶发 `sh.exe fatal error` + 「无法读取密码」的 MSYS 报错，但提交实际可能已推送成功；用 `git status -sb` 或
  `git log origin/main` 确认真实状态，不要盲目重复提交。
