## 本次新发现

- 本机 PowerShell 无 `make`，Makefile 目标需手工等价为 npm 脚本执行。
- npm 11 的 allow-scripts 策略会拦截 esbuild / vue-demi 的 postinstall，`npm rebuild` 同样被拦截；
  但 vite 仍能正常构建（esbuild 走平台包 `@esbuild/win32-x64`），无需额外处理。
- 前台执行 `npm run tauri build` 会因耗时被跳过，改用 `Start-Process` 后台 + 临时日志轮询。
- `src-tauri/Cargo.toml` 在 `git status` 中显示 `M`，但 `git hash-object` 与索引 blob 一致
  （`e279e3b…`），属 autocrlf（LF→CRLF）造成的 stat 噪音，不是实质改动，不可 `git checkout` 还原。
